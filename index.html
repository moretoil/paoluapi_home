Base URL

接口、参数、返回结构都与 OpenAI 规范一致。现有 SDK、框架和客户端不用改造，改一行地址就能切过来。

接口路径 POST /v1/chat/completions，与 OpenAI 规范一致

// 之前
const client = new OpenAI({
  baseURL: 'https://api.openai.com/v1',
  apiKey: process.env.OPENAI_API_KEY
})

// 之后
const client = new OpenAI({
  baseURL: 'https://paoluapi.xyz/v1',
  apiKey: process.env.PAOLU_API_KEY
})

const reply = await client.chat.completions.create({
  model: 'claude-opus-4-8',
  messages
})
# 之前
client = OpenAI(
    base_url="https://api.openai.com/v1",
    api_key=os.environ["OPENAI_API_KEY"],
)

# 之后
client = OpenAI(
    base_url="https://paoluapi.xyz/v1",
    api_key=os.environ["PAOLU_API_KEY"],
)

reply = client.chat.completions.create(
    model="gpt-5.6-sol",
    messages=messages,
)
# 之前
curl https://api.openai.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \

# 之后
curl https://paoluapi.xyz/v1/chat/completions \
  -H "Authorization: Bearer $PAOLU_API_KEY" \

  -H "Content-Type: application/json" \
  -d '{"model":"kimi-k3","messages":[...]}'
